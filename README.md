# 🔐 Кодовое Имя - Браузерная Игра

Многопользовательская браузерная игра "Кодовое Имя" с модифицированными правилами.

## 🎮 Как играть

### Правила:
1. **Мастер** даёт подсказку: одно слово + количество (например, «еда 3»)
2. **Игроки** не видят свои загаданные слова — только мастер
3. Можно выбрать максимум N слов (по числу из подсказки)
4. Каждый игрок видит **только свои** открытые слова:
   - 🟢 Зелёные — угаданные (свои секретные)
   - ⚪ Серые/белые — промахи (открытые зря)
   - Остальные слова выглядят как неоткрытые
5. ⚫ **Чёрное слово** — мгновенная дисквалификация!
6. 🏆 Побеждает тот, кто первым откроет все свои слова

## 🏆 Система очков

### Игроки:
- **+1 балл** за каждое правильно угаданное слово (зелёное)
- **-1 балл** за каждое неправильно угаданное слово (белое/серое)
- Дисквалификация при выборе чёрного слова

### Мастер:
- **+1 балл** за каждое правильно угаданное слово любым игроком
- **-1 балл** за каждое неправильно угаданное слово любым игроком
- **-5 баллов** если игрок дисквалифицирован (выбрал чёрное слово)
- **+10 баллов** за каждого игрока, завершившего игру

## 🚀 Запуск игры

### 1. Установите зависимости:
```bash
npm install
```

### 2. Соберите клиент:
```bash
npm run build
```

### 3. Запустите сервер:
```bash
node server.js
```

Сервер запустится на порту **3001**.

### 4. Откройте игру:
- **Локально**: http://localhost:3001
- **В локальной сети**: http://ВАШ_IP:3001

## 🌐 Игра с друзьями

### Для хоста (мастера):
1. Запустите сервер: `node server.js`
2. Узнайте IP вашего компьютера:
   - **Windows**: `ipconfig` → найдите "IPv4 Address"
   - **Mac/Linux**: `ifconfig` или `ip addr`
3. Откройте игру: `http://ВАШ_IP:3001`
4. Создайте комнату как мастер
5. Сообщите друзьям код комнаты

### Для игроков:
1. Откройте: `http://IP_ХОСТА:3001`
2. Введите своё имя
3. Нажмите "Присоединиться"
4. Введите код комнаты от мастера
5. Ждите подсказку и угадывайте слова!

## ⏱️ Таймеры

## 🔧 Решение проблем

### "Нет подключения к серверу"
- Убедитесь, что сервер запущен: `node server.js`
- Проверьте, что порт 3001 не заблокирован

### Игроки не могут подключиться
- Проверьте, что все устройства в одной сети
- Убедитесь, что файрвол разрешает подключения на порт 3001

### Слова блокируются для всех
- Это исправлено! Теперь каждый игрок видит только свои открытые слова

## 🎲 Как работает игра

1. **Создание комнаты**: Генерируется 25 случайных слов, из них 9 загаданных и 1 чёрное
2. **Распределение слов**: Загаданные слова равномерно распределяются между игроками
3. **Раунды**: 
   - Мастер даёт подсказку (1.5 мин)
   - Игроки угадывают слова (1.5 мин)
   - Каждый подтверждает свой выбор
   - Мастер видит кто ответил и переходит к следующему раунду
4. **Подсчёт очков**: +1 за правильное, -1 за промах
5. **Победа**: Первый игрок, открывший все свои слова, побеждает
