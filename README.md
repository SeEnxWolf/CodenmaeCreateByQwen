# 🔐 Кодовое Имя - Браузерная Мультиплеерная Игра

Игра "Кодовое Имя" с модифицированными правилами для мультиплеера через локальную сеть.

## 🎮 Как играть

### Правила:
1. **Мастер** (один человек) даёт подсказки: одно слово + количество (например, «еда 3»)
2. **Игроки не видят** свои загаданные слова — только мастер видит все типы слов
3. Можно выбрать максимум N слов (по числу из подсказки)
4. Каждый игрок видит **только свои** открытые слова:
   - 🟢 Зелёные — угаданные (свои секретные)
   - ⚪ Серые/белые — промахи (открытые зря)
   - Остальные слова выглядят как неоткрытые
5. ⚫ **Чёрное слово** — мгновенная дисквалификация!
6. 🏆 Побеждает тот, кто первым откроет все свои слова

## 🚀 Запуск игры

### Быстрый старт:

1. **Установите зависимости** (один раз):
```bash
npm install
```

2. **Соберите клиент**:
```bash
npm run build
```

3. **Запустите сервер**:
```bash
node server.js
```

Готово! Откройте http://localhost:3001 в браузере.

### Что происходит:
- Сервер запускается на порту 3001
- Он раздаёт готовый клиент и принимает WebSocket подключения
- Всё работает на одном порту!

## 🌐 Игра с друзьями в локальной сети

### Для хоста (мастера):
1. Запустите сервер: `node server.js`
2. Запустите клиент: `npm run dev`
3. Узнайте IP вашего компьютера:
   - **Windows**: `ipconfig` → найдите "IPv4 Address" (например, 192.168.1.100)
   - **Mac/Linux**: `ifconfig` или `ip addr` → найдите IP (например, 192.168.1.100)
4. Откройте игру по адресу: `http://ВАШ_IP:3000`
5. Создайте комнату как мастер
6. Сообщите друзьям код комнаты

### Для игроков:
1. Откройте в браузере: `http://IP_ХОСТА:3000`
2. Введите своё имя
3. Нажмите "Присоединиться"
4. Введите код комнаты от мастера
5. Ждите подсказку от мастера и угадывайте слова!

## 📱 Игра на разных устройствах

Все устройства должны быть в **одной Wi-Fi сети**.

### Пример:
- Хост: `192.168.1.100`
- Игроки открывают: `http://192.168.1.100:3000`

## 🔧 Решение проблем

### "Нет подключения к серверу"
- Убедитесь, что сервер запущен: `node server.js`
- Проверьте, что порт 3001 не заблокирован файрволом

### Игроки не могут подключиться из локальной сети
- Проверьте, что все устройства в одной сети
- Убедитесь, что файрвол разрешает подключения на порты 3000 и 3001
- Windows: Панель управления → Брандмауэр → Разрешить приложение → Добавить Node.js

### Порт занят
Измените порт в `server.js`:
```javascript
const PORT = 3002; // вместо 3001
```

И обновите `src/websocket.ts`:
```typescript
const wsUrl = `ws://${window.location.hostname}:3002`;
```

## 🎯 Особенности игры

- **Мультиплеер через WebSocket** — реальное время, синхронизация между всеми игроками
- **Каждый игрок видит только свои слова** — честная игра

## 🎲 Как работает игра

1. **Создание комнаты**: Генерируется 25 случайных слов, из них 9 загаданных и 1 чёрное
2. **Распределение слов**: Загаданные слова равномерно распределяются между игроками
3. **Раунды**: Мастер даёт подсказку, игроки угадывают слова
4. **Подтверждение**: Игроки выбирают слова и подтверждают выбор
5. **Проверка**: Сервер проверяет правильность, обновляет состояние
6. **Победа**: Первый игрок, открывший все свои слова, побеждает
